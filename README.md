# HitAir HAC/in-09H/N1_20Y — ESPHome

Локальный проект Home Assistant / ESPHome для сплит-системы **HitAir HAC/in-09H/N1_20Y**.

## Точное оборудование

- Брендовая модель внутреннего блока: **HitAir HAC/in-09H/N1_20Y**
- OEM / платформа Midea: **MSABA-09HRN1-QC2**
- Производительность: **9000 BTU/h**
- Тип: **ON/OFF, heat pump**
- Дата производства на шильдике: **12.20**
- Плата дисплея / receiver board: **EU-KFR26G/N1Y-AB1.D.01.XP1-1**
- Part number receiver board: **17122000007157**
- Схема внутреннего блока: **16022000003644**

## Цель

Получить полностью локальный климат Home Assistant без облака и довести пользовательский функционал до паритета с проектом `midea-castorama-esphome`:

- COOL / HEAT / DRY / FAN_ONLY / AUTO;
- целевая температура;
- AUTO / LOW / MEDIUM / HIGH fan;
- vertical swing;
- штатный ИК-пульт одновременно с Home Assistant;
- синхронизация состояния после команд штатного пульта;
- память пользовательской скорости вентилятора;
- память последнего рабочего режима;
- переход HEAT -> 30 °C;
- переход COOL -> 25 °C;
- persistent «Без звука»;
- корректное восстановление после рестартов ESP/Home Assistant;
- локальная работа без облака.

## Важный результат первого исследования CN3

На этой конкретной receiver board **CN3 не подтвержден как обычный 4-проводный UART**.

Нумерация CN3 в проекте — слева направо при положении платы как на исходном фото (CN1 сверху слева, CN2/CN3 справа):

| CN3 | Подтверждено прозвонкой |
|---|---|
| 1 | прямой связи с CN1 не найдено |
| 2 | ~0.2 Ω до CN3-3; ~0.3 Ω до CN1-6 |
| 3 | ~0.2 Ω до CN3-2; ~0.2 Ω до CN1-6 |
| 4 | практически напрямую на шину +5V (через CN1-7) |
| 5 | практически напрямую GND (через CN1-8) |

То есть CN3-2 и CN3-3 в штатной конфигурации электрически объединены и сидят на одном сигнальном узле CN1-6. Это соответствует известной архитектуре старых Midea receiver boards, где 5-pin CN3 используется вместе с отдельной Wi-Fi subassembly, а TX/REC в базовой конфигурации замкнуты, чтобы штатный ИК-приемник напрямую управлял основной платой.

**Следствие:** пока нельзя подключать к CN3 стандартный ESPHome `midea` UART как к TX/RX.
